# الجزء ٠١، الـ lexer

شغّل الأول قبل ما تكتب أي حاجة:

| | |
|---|---|
| ويندوز | دبل كليك على `run.bat` |
| ماك ولينكس | `./run.sh` |

هيطلعلك:

```
TokenMgrError: Lexical error at line 1, column 5.  Encountered: 'x'
```

السطر الأول في `test.txt` هو `int x = 42;` والعمود الخامس هو `x`. يعني
الأداة عرفت `int` ووقفت عند `x`.

ده مش عطل، ده أول سؤال.

## الملفات

| الملف | إيه ده |
|---|---|
| **`Lexer.jj`** | ده اللي بتكتب فيه، وده اللي بتسلّمه. مفيش غيره |
| **`test.txt`** | كود الـ Java اللي بتجرّب عليه |
| `run.bat` | التشغيل على ويندوز |
| `run.sh` | التشغيل على ماك ولينكس |
| `../javacc.jar` | الأداة نفسها، في الروت فوق. متلمسهاش |
| `build/` | بيظهر بعد أول تشغيل. كله مولّد، متعدّلش فيه ومتسلّمهوش |

## `test.txt`

الـ lexer بيقرا الملف ده. اللي جواه دلوقتي:

```java
int x = 42;
float rate = 3.14;
float avogadro = 6.02E+23;
String msg = "Hello World";
int whiles = 0;
for (i = 0; i < 10; i++) { total += i; }
if (a >= b) { System.out.println(msg); }
```

dده كود Java عادي، وشغلة الأداة إنها تقطّعه لـ tokens وتطبعهم.

ومفيش حاجة مقدّسة في السطور دي. امسحها، غيّرها، زوّد عليها. كل ما تخلّص
قاعدة حط سطر يختبرها وشغّل. لو عايز تشوف `3.14` بتطلع إزاي سيب سطر واحد
في الملف وخلاص.

وعايز ملف تاني بدل ما تلخبط ده؟ اعمل ملف جديد بأي اسم وشغّل:

```
run.bat Lexer.jj my-test.txt
```

اسم الملف مش مكتوب جوه الكود، انت بتبعته في الأمر.

## الستة أماكن

مكتوبين في `Lexer.jj` كده:

```
/* سؤال ٣ */
```

| | المطلوب |
|---|---|
| **١** | كمّل `SKIP`، ناقص الـ tab والسطر الجديد والـ carriage return |
| **٢** | جمّع أكب�� قدر ممكن من الكلمات المحجوزة في Java وزوّدهم |
| **٣** | اكتب `IDENTIFIER` |
| **٤** | اكتب `NUMBER`، رقم صحيح وبعده كسر اختياري |
| **٥** | اكتب `STRING_LITERAL`، وجرّب أكتر من string في نفس الملف |
| **٦** | العلامات اللي من حرفين، والأُسّ |

املاهم بالترتيب، وشغّل بعد كل واحد عشان تشوف الفرق.

## الملف مقسوم

| البلوك | إيه فيه |
|---|---|
| `SKIP` | اللي بيترمي، المسافات |
| `TOKEN` keywords | الكلمات المحجوزة |
| `TOKEN` identifiers | أسامي المتغيرات والدوال والكلاسات |
| `TOKEN` numeric constants | `42` و `3.14` |
| `TOKEN` string constants | `"hello"` |
| `TOKEN` special characters | `;` و `(` و `{`، بتفصل وبتجمّع |
| `TOKEN` operators | `+` و `=` و `<=`، بتعمل حاجة |
| `TOKEN` comments | الكومنتات، الجزء ده متاخد من المشروع زي ما هو |

وستة التصنيفات دول هما نفس أقسام جدول الرموز اللي الجزء ٠٢ هيطبعها.

## صيغة التعبيرات

| بتكتب | معناها |
|---|---|
| `"if"` | النص ده بالظبط |
| `["0"-"9"]` | حرف واحد من المدى |
| `["+","-"]` | حرف واحد من القايمة |
| `~["x"]` | أي حرف ما عدا x |
| `~[]` | أي حرف خالص |
| `A B` | A وبعده B |
| `A \| B` | A أو B |
| `( A )*` | صفر أو أكتر |
| `( A )+` | واحد أو أكتر |
| `( A )?` | موجود أو لأ |

`["0"-"9"]` لوحدها حرف واحد. عشان تاخد أكتر حط `+` أو `*` بعدها.

و `~["x"]` بتشمل السطر الجديد. فلو كتبت قاعدة كومنت بـ `~[]` من غير
استثناء هتبلع الملف كله.

## لو وقفت

| المشكلة | الحل |
|---|---|
| `javac is not recognized` | الـ JDK مش مركّب، أو مقفلتش الـ terminal بعد ما ركّبته |
| `javacc refused the file` | غلطة في `Lexer.jj`، والرسالة فيها رقم السطر. غالباً `>` ناقصة أو فاصلة زيادة |
| النافذة بتقفل بسرعة | شغّله من terminal، افتح `cmd` في المجلد وبعدين `run.bat` |
| `Lexical error` | ده المتوقّع في الأول |

ولو لسه واقف اسأل في جروب التليجرام ومعاك صورة الشاشة.
